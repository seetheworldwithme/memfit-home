# 关于 Memfit AI

**Memfit AI** 是 [Yaklang](https://yaklang.com) 官方开源的网络安全 AI Agent 编排框架。我们致力于用递归式双引擎（ReAct + Plan）架构，让 AI 在安全自动化与代码审计场景中拥有"看得见的行动力"。

## 与 Yaklang 的关系

Memfit AI 是 **Yaklang 官方项目**，由 Yaklang 团队设计与维护，与 Yaklang 核心安全能力深度协同，是 Yaklang 生态在 AI Agent 方向的官方落地。

## 核心理念

- **递归式双引擎**：ReAct 引擎负责实时推理与行动，Plan 引擎负责任务分解与规划，二者递归协作。
- **看得见的行动力**：强调可观测的执行过程、自旋检测与可靠性保障，而非黑盒输出。
- **开源开放**：以 Apache-2.0 协议开源，欢迎社区参与。
